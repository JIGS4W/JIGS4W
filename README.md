# ☕ Cafe POS System

A simple web-based Point of Sale system for managing orders in a cafe.

---

## 🌐 Live Demo
👉 https://cafepos-system.vercel.app/

---

## 📌 About This Project

This project is built to simulate a real-world cafe POS system.  
It allows users to manage orders, calculate totals, and handle basic transactions.

---

## ✨ Features

- Create and manage orders
- Add/remove menu items
- Calculate total price automatically
- Responsive design (mobile & desktop)

---

## 🛠 Tech Stack

- Frontend: Next.js, React
- Styling: Tailwind CSS
- Backend: Node.js
- Database: SQLite
